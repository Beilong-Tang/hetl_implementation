# HeTL 实现：论文内容与复现假设

## 论文明确给出的内容

论文式(4)定义目标函数：

```text
||S - Vs Ps||_F² + ||T - Vt Pt||_F² + beta ||Vs - Vt||_F²
```

并要求：

```text
VsᵀVs = I
VtᵀVt = I
```

论文式(5)(6)给出 Vs、Vt 的梯度；式(7)(8)给出固定 V 后 P 的最小二乘更新。
Algorithm 1 指定输入为 S、T、beta、k、学习率 alpha，最多运行1000步，并在目标函数
收敛时提前停止。

## 论文没有说明，本项目必须补充的内容

### 1. 初始化

论文只写 `Initialize: Vt, Vs, Pt, Ps`，没有说明初始化方法。

默认使用截断 SVD 的左奇异向量初始化 Vs、Vt。原因：

- 它天然给出正交列；
- 是低秩矩阵重构的标准稳定起点；
- 不依赖随机运气，便于组员复现。

代码也支持 `initialization="random"`，用于敏感性实验。

### 2. 正交约束

论文写出 `VᵀV=I`，但没有说明梯度更新后如何维持该约束。

本实现每次更新 Vs、Vt 后执行 QR retraction，将矩阵重新投影到正交列空间。若不做这一步，
代码实际上没有执行论文声明的约束，而且 V 与 P 之间会出现任意缩放问题。

### 3. P 的更新方式

论文正文式(7)(8)是闭式最小二乘解，而算法框中的排版看起来像梯度更新，二者存在歧义。

本实现采用式(7)(8)的闭式更新。由于 V 已正交：

```text
P = (VᵀV)⁻¹VᵀX = VᵀX
```

这样不需要显式求逆，数值更稳定，也严格最小化固定 V 时的重构项。

### 4. 收敛条件

论文只说“直到目标函数收敛或达到1000步”，没有给容差。

本实现定义：目标函数相对变化连续10步小于 `1e-7` 时收敛；否则最多1000步。每一步的总损失、
两个重构损失和对齐损失都会保存，便于检查。

学习率同样未由论文公开。真实 DoS→R2L 数据上的数值稳定性试验显示 `1e-3` 在当前归一化和
正交化实现中会使目标函数明显上升，而 `1e-5`、`1e-4` 保持稳定，因此正式默认使用 `1e-4`，
并保留 `[1e-5, 1e-4]` 作为敏感性范围。这是数值实现选择，不是论文给定值。

### 5. 源域和目标域的逐行对应

`||Vs-Vt||_F²` 要求两个域行数相同，并直接比较相同行号。然而论文没有说明一条 DoS 记录
应与哪一条 R2L 或 Probe 记录配对。这是论文最重要的复现缺口之一。

严格版本采用预处理文件中现有的确定性行顺序，不使用目标标签重新配对。原因：按标签配对会在
表示学习阶段使用本应不可见的目标标签，造成泄漏。该选择仍然是人为行配对，因此后续应增加
CORAL/MMD 等分布级对齐作为敏感性对照，但不能把它冒充论文原方法。

### 6. beta 与 k 的选择指标

论文说明使用500条有标签目标数据选择 beta 和 k，但没有说明优化哪个指标。

本项目选择目标验证集 attack F1，因为论文 Table III 将 F1 作为核心指标，而且 R2L 任务中
Accuracy 约0.5可能来自“全部预测为正常”。若 F1 相同，则依次以验证 Accuracy、ROC-AUC和较小
的 k 作为决胜条件。1490条目标测试标签不参与选择。

### 7. 传导式设置

HeTL 拟合时可以使用全部 X_target，包括最终测试记录的特征，但不使用其标签。这与论文将目标
域作为无标签输入共同学习表示的传导式设定一致。若研究真实在线部署，应另外增加只使用目标适配
子集特征的归纳式实验。
